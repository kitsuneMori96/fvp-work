Sample project (ships with the package; double-click works out of the box).

- scene.json: one preview snapshot (prim layout).
- replay.json: full timeline (899 rows) for the row/track panel.
- tex/: decoded textures referenced by relative path tex/*.png.

Use your own project: pass its dir to start_editor (.sh/.bat),
or switch sample_dir in the web config panel (takes effect immediately).
